# testing-lab

Two small projects for practising automated tests with Vitest.

| folder | what it is | the lab |
|---|---|---|
| `gradebook/` | plain JavaScript functions: averages, letter grades, late penalties | unit tests with Vitest |
| `gradebook-api/` | the same functions behind an Express API | integration tests with supertest |

Each folder is its own project. Move into one, then:

```
npm install
npm test
```

Node.js 20 or later.
